# Fit-Tracker
A custom fit tracking application.
A clean, responsive web application built with HTML, CSS, and JavaScript to help users track workouts, monitor daily activity, and stay on top of their fitness goals.



## Features

* **Workout Logging:** Input exercises, sets, reps, and workout duration.
* **Local Storage Integration:** Saves your fitness data directly in your browser so you don't lose progress on refresh.
* **Responsive Design:** Optimized to look great on both desktop and mobile screens.



## Tech Structure

* **HTML5:** Semantic markup structure for the dashboard and input forms.
* **CSS3:** Custom styling, layout design, and responsive media queries.
* **JavaScript (ES6+):** Dynamic interactivity, DOM manipulation, and data persistence.
